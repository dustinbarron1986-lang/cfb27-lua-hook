\# CFB27 Coordinator Mod - Agent Rules



\## Approval required before file changes



Before creating, modifying, renaming, moving, or deleting ANY file in this repository:



1\. Explain exactly what you intend to change.

2\. List every file that would be created or modified.

3\. Briefly explain why each change is needed.

4\. Show the important proposed logic/change at a high level.

5\. Ask:



&#x20;  Proceed with these file changes? (y/n)



6\. STOP and wait for my response.

7\. Do not write or modify any file unless I answer "y" or otherwise explicitly approve it.



If I answer "n", do not make the changes. Discuss alternatives instead.



\## Read-only research



You may inspect files, search the repository, read documentation, inspect logs, and run commands that do not modify repository files without asking first.



\## Commands that affect the running game



Before executing any command or script that:

\- writes game memory,

\- patches executable code,

\- calls an unverified native game function,

\- installs a hook/breakpoint that could alter execution,

\- or otherwise risks destabilizing College Football 27,



explain what the command will do and ask for approval first.



Safe read-only memory scans and previously validated read-only probes may be run without approval unless they require me to interact with the game.



\## Game interaction



If an experiment requires me to change something in the game:

\- tell me the exact game state required,

\- tell me whether to pause or unpause,

\- tell me whether I should be on offense or defense,

\- tell me whether I should be at the play-call screen or pre-snap,

\- then STOP and wait for me.



Do not assume I completed a game action until I confirm it.
